# AgentDesk Backend Microservice (Planned)

This directory is reserved for the upcoming Python + FastAPI backend worker and Playwright automation pipeline.

## Planned Architecture
- **Framework**: FastAPI (async ASGI service running on localhost)
- **Scraper / Research Engine**: Playwright for Chromium automation
- **AI Interface**: Unified provider abstraction (Cloud AI APIs & local models)
- **Data Export**: CSV and OpenPyXL / Pandas Excel generation
- **Human Approval Gate**: Intercepts all email drafts before transmission

*Note: In accordance with Phase 1 constraints, no scraping, email dispatch, or API keys are active yet.*
